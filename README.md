# 🌍 Hometown Homepage

## 📌 Overview

Hometown Homepage is a simple yet visually appealing web page that showcases a hometown with a hero section, activities, and a guide section (presented in a card format). This project was built from scratch as part of the **Scrimba Frontend Developer Career Course** under HTML and CSS web development basics.

🚀 The goal of this project was to **revise my HTML and CSS skills** while also incorporating **React** for additional practice.

---

## 🎯 Purpose

- Reinforce **HTML & CSS** fundamentals.
- Improve **React** development skills.
- Learn how to replicate a **Figma mockup design** in code.
- Understand layout structuring, component building, and styling.

This project was based on a **Figma mockup design** provided by Scrimba, allowing me to **practice translating a design into a fully functional web page**.

---

## ✨ Features

✔ **Hero Section** - A welcoming introduction to the hometown.  
✔ **Activities Section** - Showcasing fun things to do in the area.  
✔ **Guide Section (Card Format)** - Highlighting key places and recommendations.  
✔ **Responsive Design** - Ensuring usability across different screen sizes.  
✔ **Built with React** - Although it could have been done with just HTML and CSS, I chose React to sharpen my skills.

---

## 🛠️ Technologies Used

- **HTML5** 🏗️
- **CSS3** 🎨
- **React** ⚛️
- **Figma** 🖌️ (for design reference)
